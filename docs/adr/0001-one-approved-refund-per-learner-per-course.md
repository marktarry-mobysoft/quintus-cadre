# One Approved Refund Request per learner per course, ever

A learner who has had a Refund Request approved for a course can buy that course again, but can never have a second Refund Request approved for it. Without this rule, buy, watch, refund, repeat would give anyone free access to a course, because each new purchase would open a fresh Refund Window and a fresh watch allowance. This rule is deliberate. Don't relax it to "one per purchase", and don't add any flow (re-purchase discounts, extended windows, account merges) that would let the combination happen again.
